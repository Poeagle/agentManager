# 平台字体

在“平台管理 → 平台设置 → 外观 → 平台字体”选择系统默认、微软雅黑、苹方、思源黑体、Noto Sans CJK、霞鹜文楷或 Arial，也可以选择“自定义字体”填写一个字体名称，例如 `LXGW WenKai`。

选择后立即预览界面与对话文字；点击“保存设置”持久保存。关闭设置但未保存时恢复上次保存的字体，保存失败也不会把预览当作已保存。选择“系统默认”并保存即可恢复默认字体。

字体来自浏览器所在设备的本地字体，不下载字体或访问外部字体服务。字体名称须与设备安装的名称匹配，缺失字符或字体未安装时回退到默认字体。不同设备可能因安装的字体不同而显示不同效果。代码、文件差异和原始终端继续使用原有等宽字体。

此选项沿用平台外观设置权限：有“平台设置”写权限的用户可以修改，保存后作为全平台默认值，页面重新读取设置后生效；当前页面立即生效。仅有读权限的用户可以查看，不能更改。
