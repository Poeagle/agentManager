# UI 信息密度检查

目标：在相同可用面积内突出名称、状态、配置值、主要操作与结果，减少装饰和重复说明；不通过过小字体或删除必要安全提示提高密度。

## 检查范围与结论

代码检查覆盖 `dashboard/src/components` 的全部页面组件，以及 `App.tsx` 和共享样式。按用途处理，不统一压缩终端、编辑器和文档画布。

| 区域 | 处理原则／当前布局 |
| --- | --- |
| 项目列表、会话历史、监控、用户、角色、项目授权、Agent API | 紧凑表格／列表，名称、状态、操作优先；详情保留现有打开或展开方式 |
| 项目新增／编辑 | 共用居中弹窗，保留背景列表；长内容在弹窗内滚动；短字段限制宽度；长路径、提示词与配置文件保持可阅读空间 |
| 定时任务 | 独立列表与编辑页；配置、提示词、记录顺序展示；右上角固定保存；规则中直接标出且／或；永久截止限制折叠 |
| 平台设置 | 控件高 32px；字段组按可用空间排列；数字不再拉满整列；启动命令并列展示，避免大卡片嵌套 |
| 账户、授权及角色编辑 | 短字段紧凑排列；权限信息保持完整，不移除安全边界说明 |
| Session 启动、技能 | 项目“打开”和会话栏“＋”共用打开方式弹窗；技能保持列表与安装参数 |
| 顶栏、项目／会话标签与左侧导航 | 保留紧凑导航及资源状态；名称、选中与告警信号优先 |
| 文件树、Git、终端及会话历史输出 | 保留工具条与内容区域；不压缩终端行距、不更改输入行为 |
| 文档、PDF、Office、表格、图形预览 | 保留画布、缩放和换行空间；不套用配置表单的尺寸 |
| 登录、确认、关闭标签、传输、恢复反馈及错误边界 | 保持按内容大小的弹窗与必要的状态／错误／危险操作说明 |

页面外边距通过 `.page-content` 统一；`.compact-form` 和设置专用样式只作用于对应区域，不对所有输入框或文本应用全局缩放。

## 平台展示的一致性

同一种展示和交互只保留一套公共实现。平台列表及其展开的子列表统一使用 `components/table/DataTable.tsx`；页面提供字段、数据、列宽与业务操作，不自行实现表格容器、表头、展开控件或状态行。

- 项目、项目会话、用户监控及其项目／会话子表、服务器资源、用户及角色分配、角色及授权矩阵、项目授权、Agent API、会话历史、定时任务及执行记录，共 15 处表格已接入。
- 表头颜色、字号、单元格间距、边框、滚动、排序与筛选由公共组件统一处理。加载、请求失败、无数据和无筛选结果均保留表头，在表内显示状态。
- 展开详情使用 `TableDetailRow`，加减号使用 `TableExpandButton`。展开子列表仍使用 `DataTable`，不增加独立的卡片标题或工具栏。
- 表格操作使用 `TableActions`、`TableActionButton` 和 `RowActionsMenu`，主要操作直接显示，其他管理操作放在“更多”中。
- 项目会话历史提供“操作／删除”列，已完成、失败或关闭的本人会话经确认后删除。请求成功才移除记录和打开的标签页，并更新持久化状态；失败保留原记录供重试。运行中的会话需要先关闭，接口也会拒绝直接删除活动记录及其他用户的记录。
- `tests/table-consistency.test.ts` 扫描全部页面组件，禁止重新引入独立的表格结构、展开行及样式。浏览器测试比较项目、授权和监控各级表格的实际结构与计算样式，并检查窄屏滚动。

表格文件预览展示文档自身的工作表单元格，保留文档画布行为。

项目新增／编辑、Session／Terminal 打开方式共用 `components/Dialog.tsx`，统一居中位置、遮罩、标题、关闭按钮、焦点范围、Escape 关闭、关闭后焦点恢复及提交期间的关闭限制。点击新增项目或项目标签栏的新增入口时，在当前列表上打开弹窗，不切换到单独的表单页面。

## 服务器平台的冗余入口检查（2026-10-14）

检查范围：扫描所有 42 个页面组件、`App.tsx`、`main.tsx`、前端 API 调用及服务端启动桌面应用的命令，追踪命中的调用链。

| 发现 | 处理 |
| --- | --- |
| 项目“更多”中的服务器文件管理器、系统终端入口 | 移除，保留编辑与移除项目 |
| 文件树右键菜单中的 OS 文件管理器、终端入口 | 移除，保留导出、复制及获授权的文件操作 |
| 网页终端“Pop out to system terminal” | 移除按钮、API、服务端启动桌面终端及专用 release 路径 |
| 旧 Tauri WebView 将外链转发给服务器浏览器 | 移除拦截、`/api/open-url` 和未使用的 Tauri API 依赖；外链由当前浏览器处理 |
| 项目 Home 启动表格 | 已移除，项目打开与顶部“＋”共用创建弹窗 |
| 已关闭会话出现在项目展开行 | 展开行只显示活动会话，完整记录在会话历史中查看 |

文件导出和上传操作的是当前浏览器设备，具有实际用途。终端显示刷新和连接重试、会话历史和恢复、外部会话接管分别服务不同流程，保留。tmux/dtach 持久化与重启恢复继续使用，不启动桌面窗口。

## 验证

2026-10-14 桌面功能清理验证：前端 145 项、后端 288 项测试通过（后端另有 2 项跳过），双端生产构建通过。隔离浏览器使用模拟 API 与终端连接，检查项目菜单仅含编辑／移除、文件右键菜单保留导出但无桌面启动项、终端工具栏无系统终端弹出。没有启动用户的真实 CLI 会话。

2026-10-14 按用户要求删除项目内嵌浏览器：移除入口、组件、网页标签及恢复／排序／持久化代码，并移除默认网页地址的表单、API、导入导出及数据库字段。v12 升级只清理对应旧字段和项目状态中的网页标签键，保留项目、会话、文件浏览器与其他配置；升级前自动备份数据库。

自动化浏览器检查覆盖定时任务新建、保存、列表、重新编辑、执行记录，以及平台设置；检查 1800px 和 900px 下的布局、短字段宽度和滚动后保存按钮位置。单元测试覆盖条件编辑、混合分组、执行记录与设置行为。其余区域已做代码层审查，未声称逐个实测所有真实会话或预览格式。
