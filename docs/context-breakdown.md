# 会话上下文分类

上下文占用条可打开分类详情，布局参照 DolphinDB Manager 的 AgentContextUsage：占用摘要、分类色条、Token 与占比、按工具或注入来源展开的明细。整体占用使用原生最近一轮 token_count，分类使用当前会话 JSONL 的可见内容；两者的分母不同，不能混成一份精确账单。

GET /api/sessions/:id/context-breakdown 使用与会话读取一致的授权，并检查 agent_api/read。平台通过可选 telemetry.contextBreakdown 契约访问适配器；未实现的 Agent 返回统一的不支持结果。Codex 适配器使用该会话绑定的原生引擎查询日志路径，通过账号已有 SSH 或本机通道分析，不调用模型、恢复会话、修改配置或查询账号额度。

分类包括系统提示、上下文注入、用户消息、助手纯文本、工具调用和工具结果，按注入类型/工具名保留子项。只统计 response_item 内容，避免重复计算 event_msg 中的同一消息。存在 history_base 时复用原生历史图读取器验证继承前缀；遇到完整 compacted.replacement_history 时替换前面的分类，避免把已经压缩掉的历史当作当前内容。没有完整替换历史时标记部分数据。

与参考项目未加载匹配词表时的离线回退一致，当前分类采用字符数 / 3 向上取整，标记 exact:false、method:characters_div_3。不会安装或下载分词器；模型消息包装、不可见推理、完整工具定义、图片输入、原生截断或隐藏提示词不由文本长度编造精确数值。工具 schemas 与图片未提供时显示未知。分类之和是可见日志文本的粗估量，不等于原生真实上下文 Token，也不等于会话累计消耗。

每次最多读取最近 64 MiB、20 万条记录、单条 16 MiB，最多并行 4 个请求，超限或半行、异常行标记部分；继承图仍执行现有循环、目录、文件身份和总量校验。响应最多 512 KiB、进程最长 30 秒；目标账号侧只返回计数与分类名，不返回提示词、工具参数/输出或凭据正文。相同引擎/账号/原生会话的并发请求合并，计数缓存最多 32 份、30 秒；显式 refresh=true 可重新读取，刷新不会发起模型请求。

原生用量事件与原生线程读取能力见 [OpenAI App Server 文档](https://learn.chatgpt.com/docs/app-server)。分类重建根据本项目实际 JSONL 读取路径实现，未知部分保持未知。
