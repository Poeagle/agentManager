# 个人共享资源

打开“平台管理 → 个人 → 共享资源”，设置共享工作目录、生效项目范围和 `.env` 文件路径。凭据文件与使用提示词分开维护。

## 配置文件和提示词

1. 选择现有 `.env`，或填写共享工作目录内的新文件路径。文件的父目录需要存在。
2. 在“共享资源使用提示词”中说明变量名、认证方式和访问方法。Token、密码、API Key 写在 `.env` 中，提示词只写用法。
3. 保存配置，再点击“打开文件”。编辑器显示实际文件内容；保存时直接写回该文件，文件不存在时创建。关闭编辑器后清除页面中的文件内容。

文件编辑器采用内容校验避免覆盖外部程序或其他页面的新修改。遇到文件冲突时保留当前草稿，可重新打开文件核对。文件写入权限为 `600`；保存配置、打开页面或启动会话时不会将凭据内容自动加载到提示词。

例如，Jira 和 Confluence 可共用 `CONFLUENCE_EMAIL`、`CONFLUENCE_TOKEN`，地址使用 `ATLASSIAN_BASE_URL`。提示词说明两个产品共用 Basic 认证，并要求本地 HTTP 程序读取凭据后访问 API。普通网页跳转登录页不表示 Token 无效。

GitLab 可配置 `GITLAB_HOST`、`GITLAB_TOKEN`。项目级 Token 的适用项目写在提示词中，不能假定拥有其他项目权限。Jira 项目键、Confluence 页面 ID 和发布规则继续由各项目维护。

## 哪些情况下加载

同时满足以下条件时，AI 会话可以获得共享说明：

- 会话属于配置的当前账号。
- 已启用共享资源。
- 项目的真实路径位于生效范围及其子目录。

新建 AI 会话、显式重载标签页、恢复会话时加载或更新说明。单纯切换标签页、刷新网页、重连已运行的会话或普通发消息不重复加载。修改 `.env` 后，本地程序下次读取即使用新值；修改提示词、文件路径或范围后，已有会话需要重载。

启动上下文只包含共享目录、凭据文件位置和使用提示词。Codex 通过配置或原生 developer 消息接入；恢复已加载的线程时显式补充 developer 上下文，不提交用户消息，也不额外触发模型回复。恢复请求只读取元数据，避免长会话的完整历史超过连接大小限制。

Codex 对话中会显示与项目规则相同的折叠条目“自动信息 · 共享资源”，包含加载时间、凭据文件路径和使用说明。它不展示 `.env` 内容，不计为用户问题，不重置对话计时。其他 developer 指令和工具结果继续保持不可见。历史中已有的共享资源记录也能显示，无需重新发送问题。

普通终端、平台外自行启动的 CLI 不自动加载。禁用配置会阻止后续接入，但不会撤销已经进入旧会话的文字或外部服务的 Token。

## 账号范围与保存位置

数据库按用户保存目录、文件路径、提示词、启用状态及修订号；凭据保存在用户选择的真实 `.env` 文件，不另存一份配置值，也不写入全局 shell 环境。不同账号不能在页面中认领同一个凭据文件，文件编辑接口始终以当前账号保存的路径为准。通用文件接口不能绕过个人入口读取该文件。

这里采用平台账号和目录范围管理，沿用平台现有的会话权限机制，没有新增 systemd 服务或进程隔离。服务器管理员仍可管理主机文件。选择或改动提示词及文件内容应由账号所有者负责。

更换文件路径只更改配置引用，原文件保留；删除共享配置也不删除凭据文件。备份时保留平台数据库和用户选择的 `.env` 文件即可。

## 从已有项目预填

```sh
npm run build:server
node scripts/import-shared-resources.mjs \
  --db /path/to/agentmanager.db \
  --username your-account \
  --source-project /path/to/dolphindb_manager \
  --directory /path/to/workspace
```

导入器核对项目归属，只导入相关访问变量，不输出凭据。它在共享目录创建 `.env` 并预填独立使用提示词；不会覆盖已有 `.env` 或已配置的文件引用。对于早期键值版本，优先保留页面中已保存的值。来源项目 `.env` 保持原样；原项目自行读取旧文件的脚本仍使用原入口。
