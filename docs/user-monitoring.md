# 用户连接与登录信息

用户监控将浏览器连接、登录凭证和后台工作会话分别统计。连接状态不再由最近两分钟是否有 API 请求推断，也不由 Agent 是否正在运行推断。

网页通过 `/api/stream` 建立已认证的实时连接。初始握手确认连接存在；之后服务端每 25 秒发送 WebSocket 协议 ping，以浏览器回复的 pong 更新心跳。75 秒内有握手或 pong 的连接为在线；仍未关闭但心跳超时为连接异常；没有连接为离线。表格每 5 秒采样，突然断网的检测存在最多约 80 秒延迟。正常关闭页面时连接立即移除，下次采样反映离线；同一账号还有其他在线页面时保持在线。认证失效或账号禁用后不计入在线。

最近活动记录认证请求或已验证心跳的时间，登录时间取登录凭证的创建时间。后台 Agent 活跃不会使用户在线；平台 AI 内部凭证单独标为 internal，不列为浏览器登录。

用户行展示最近访问 IP 和设备／浏览器，展开后查看每个有效登录的登录时间、登录 IP、最近访问 IP、连接数及最后心跳。所有时间带日期，按浏览器本地时区显示。登录退出或凭证过期后不再显示该有效登录，本表不是永久登录审计日志。旧记录未采集的登录 IP 保持“未记录”，不会用当前 IP 补造历史。

IP 来自实际连接对端，IPv4 映射地址统一显示为 IPv4。开发环境 Vite 代理使用实际 socket 对端覆盖专用来源头，API 仅信任来自回环地址的该头；远端自带的来源头和通用 X-Forwarded-For 不作为依据。其他反向代理后的地址可能显示为代理地址，不提供推测的地理位置。设备／浏览器从客户端报告的 User-Agent 提取，仅供辨识；无法识别时显示“其他客户端”。

登录元数据仅在有用户监控权限的接口中返回，不返回 cookie、登录 token 或密码信息。更新使用现有连接与本地数据库，不调用模型或外部地理位置服务。
